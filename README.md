# Noor Shahid | Portfolio

Portfolio website for Noor Shahid, a social media manager and Meta Ads specialist based in Lahore, Pakistan.

Live site: https://noorshahid-pk.netlify.app

## What's on the site
- About, services and skills
- Resume and experience
- Work: my social media accounts
- Packages and pricing
- FAQs
- Contact form and thank-you page

## How to update it
1. Open `index.html` on GitHub.
2. Click the pencil icon, make the change, then click Commit changes.
3. The live site updates automatically in about a minute.

## Built with
HTML, CSS and JavaScript. Hosted on Netlify.
